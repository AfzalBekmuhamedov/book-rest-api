Book REST API — Django REST Framework

Book REST API is a RESTFULL API built with Django REST Framework for managing authors and books.

The project allows authors and books to be created and stored in the database, with relationships between them.

Purpose

The purpose of this project is to practice building a REST API with Django REST Framework and working with related database models.

Features

- Author Management
- Book Management
- Author and Book relationships
- Database storage
- RESTful API endpoints
- CRUD operations
- Django REST Framework

Data Structure

The project contains two main entities:

- Author
- Book

Authors can be created and books can be created and connected with the corresponding authors.

How It Works

1. An author is added to the database.
2. A book is created.
3. The book is connected to its author.
4. The related information is stored in the database.
5. The API can be used to access and manage the data.

Technologies
